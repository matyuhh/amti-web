# Matías Gutiérrez - Portfolio

A simple, clean portfolio website built with vanilla HTML, CSS, and JavaScript.

Fullstack developer with more than 8 years of experience building and maintaining scalable and innovative applications.

## Running the App

### Option 1: Using Python's built-in server

```bash
python -m http.server 8000
```

Then open your browser to `http://localhost:8000`

### Option 2: Using Node.js http-server

```bash
npx http-server -p 8000
```

Then open your browser to `http://localhost:8000`

### Option 3: Using VS Code Live Server

Install the "Live Server" extension in VS Code and click "Go Live" button.

## Structure

- `index.html` - Main HTML file with all content
- `styles.css` - All styling
- `app.js` - JavaScript for interactive features
- `src/core-ui/fonts/` - Inter font files
